Projects

Open-source research code and tools, all available on GitHub.

ESTGCN

Graph neural networks for rainfall–runoff prediction

Event-based spatio-temporal graph convolutional networks predicting discharge across five nested HUC12 basins in the Kissimmee River / Lake Okeechobee system. Compares hydrologic-topology graphs against k-NN proximity graphs across 72 reproducible scenarios (LSTM, GRU, RNN × three loss functions).

Python Keras / TensorFlow Hydrology
Code

Florida Climate–Vegetation Analysis

43 years of NDVI, temperature and precipitation (1982–2024)

Long-term trends in vegetation greenness across Florida from NOAA CDR NDVI and nClimGrid, using Theil–Sen / Mann–Kendall trends, EOF decomposition and spatial regression, tested against drought indices, radiation, hurricanes, ENSO and Everglades water levels. Fully reproducible notebook.

Python Remote Sensing Spatial Statistics
Code

Semi-Automated Flood Risk Mapping

Multi-basin, multi-scenario workflow for ArcGIS Pro

ArcPy notebooks that automate flood modeling for Florida watershed master planning: HUC subsetting, ArcHydro preprocessing, soil storage, Cascade 2001 inputs, z-score probabilistic flood maps and infrastructure risk scoring. Handles 48 scenarios per region (rainfall, sea-level rise, tides) and cuts manual processing by over 85%.

ArcPy LiDAR DEM Flood Risk
Code

FloodFusion

Interactive flood mapping app on Google Earth Engine

Fuses Sentinel-1 SAR and Sentinel-2 optical imagery with a Random Forest classifier to map flood extent. Users draw an area, bring their own training data, filter by slope and patch size, and export flooded area and GeoTIFFs — no coding required.

Earth Engine SAR Random Forest
Code Live app
